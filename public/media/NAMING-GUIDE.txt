 HOW THE PATHS WORK
--------------------------------------------------------------------------------
In content/story.ts, every media slot has a `src` field. Right now they are all
empty (`src: ""`), which is why you see the dashed placeholders on the page.

When you drop a file in this folder, the exact path I will put into its slot is:

        /media/<exact-filename-with-extension>

Example: drop `jammu-1.jpg` in this folder -> I set that slot to `/media/jammu-1.jpg`.

--------------------------------------------------------------------------------
 SUPPORTED FORMATS
--------------------------------------------------------------------------------
  Photos : .jpg / .jpeg, .png, .webp, .gif are all fine. .jpg is preferred
           (best balance of quality and small file size for photos).
  Video  : .mp4 (H.264) is strongly recommended — it plays in every browser.
           .webm also works.

  • Keep filenames LOWERCASE with NO SPACES. Use hyphens (-) to separate words.
  • Filenames are case-sensitive on most web servers, so match the list exactly.

  Note: If your photo is a .png / .webp / .jpeg and you would rather keep that
  extension, that's totally fine — keep the SAME base name (e.g. `jammu-1.png`)
  and just TELL ME the exact filename so I wire the matching path. If in doubt,
  simply rename it to .jpg to match this list exactly.

--------------------------------------------------------------------------------
 PLEASE COMPRESS YOUR VIDEOS
--------------------------------------------------------------------------------
Long or high-resolution videos make the page slow to load, especially on mobile.
Before dropping the two .mp4 files in here, compress them. A good target:
  • 720p–1080p resolution
  • H.264 codec
  • short clips, only a few MB each
